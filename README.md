# FizzBuzzWhizz TDD

This repository contains the solution to the **FizzBuzzWhizz** kata, developed applying **TDD (Test-Driven Development)**.

---

## Problem Description

The goal of the exercise is to implement a `game(input: number)` function that takes a natural number greater than zero and returns a result based on the following rules:

- **"Fizz"**: If the number is divisible by 3.
- **"Buzz"**: If the number is divisible by 5.
- **"FizzBuzz"**: If the number is divisible by both 3 and 5 at the same time.
- **"Whizz"** *(Bonus Rule)*: If the number is **prime** (evaluated for numbers from 2 to 100).
- **Combinations**:
  * **"FizzWhizz"**: If it is divisible by 3 and is also prime (e.g., 3).
  * **"BuzzWhizz"**: If it is divisible by 5 and is also prime (e.g., 5).
- **Original number**: If it does not satisfy any of the conditions above, return the number itself.

---

## Running Tests

To verify the correct functioning of the rules through unit tests, run the following command in your terminal:

"npm test"
